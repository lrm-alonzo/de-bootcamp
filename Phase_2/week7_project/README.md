# PROJECT · Week 7 Project: Deploying Scripts to the Cloud

# Goal
Deploy data processing scripts to AWS and make the processed data accessible in the cloud.

# Features
1. Fetch employee details from an API and save them as a JSON file.
2. Fetch employee attendance data from a manually uploaded CSV file.
3. Combine employee details and employee attendance data into a single CSV file.
4. Make the combined data available in the cloud for viewing and analysis.

# How it works
This project consists of two jobs and one crawler:

1. fetch-employee-job
  - Runs the fetch_employee.py script.
  - Fetches employee details from an API.
  - Saves the data in JSON format.
  - Automatically uploads the JSON file to an Amazon S3 bucket.

2. employee-attendance-etl
  - Runs the employee_attendance_etl.py script.
  - Retrieves employee details from the JSON file generated by fetch-employee-job.
  - Retrieves employee attendance data from a manually uploaded CSV file stored in an Amazon S3 bucket.
  - Transforms the data by:
    - Renaming columns
    - Updating data types
    - Adding new columns
  - Combines the cleaned employee details and attendance data into a single CSV file.
  - Stores the final output in Amazon S3 for cloud-based access.

3. AWS Glue Crawler - employee_attendance_crawler
  - Runs after the final CSV file is generated and stored in Amazon S3.
  - Scans the output data stored in the S3 bucket.
  - Automatically infers the schema and updates the AWS Glue Data Catalog.
  - Creates or updates the metadata required for querying the data.
  - Enables Amazon Athena to access and query the processed employee data directly from S3.
