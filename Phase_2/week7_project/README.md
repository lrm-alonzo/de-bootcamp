# Employee Attendance ETL Pipeline Using AWS
- Data Engineering Bootcamp – Phase 2, Week 7 Project
-----------------------------------------------------------------------------------
# Goal
- Build and deploy an AWS-based ETL pipeline that ingests employee and attendance data, transforms and combines the datasets, and makes the processed data available for cloud-based analytics and querying.
-----------------------------------------------------------------------------------
# Features
1. Fetch employee details from an API and save them as a JSON file.
2. Read employee attendance data from a manually uploaded CSV file.
3. Combine employee details and attendance information into a single dataset.
4. Apply data transformations and standardization.
5. Store processed data in Amazon S3.
6. Automatically catalog the data using AWS Glue Crawler.
7. Query processed data using Amazon Athena.
-----------------------------------------------------------------------------------
# How it works
  This project consists of two AWS Glue jobs and one AWS Glue crawler.

1. fetch-employee-job
Purpose: Retrieve employee details from an API and store the data in Amazon S3.

Process:
  - Runs the fetch_employee.py script.
  - Fetches employee details from an external API.
  - Converts the response into JSON format.
  - Uploads the JSON file to Amazon S3.

Output:
s3://employee-data-project/employee_details/

2. employee-attendance-etl
Purpose: Transform and combine employee details with attendance data.

Process:
  - Runs the employee_attendance_etl.py script.
  - Reads employee details JSON generated by fetch-employee-job.
  - Reads attendance CSV uploaded to Amazon S3.
  - Performs data cleansing and transformations:
  - Renames columns
  - Updates data types
  - Creates additional transformed columns
  - Joins employee details with attendance records.
  - Generates a consolidated CSV file.
  - Stores the processed output in Amazon S3.

Output:
s3://employee-data-project/processed/

3. AWS Glue Crawler - employee_attendance_crawler
Purpose: Create metadata that makes the processed data queryable.

Process:
  - Scans the processed data stored in Amazon S3.
  - Automatically infers the schema.
  - Updates the AWS Glue Data Catalog.
  - Creates a table definition for querying.
  - Enables Amazon Athena access.
-----------------------------------------------------------------------------------
# AWS Services Used

Service:
- Amazon S3:               Data storage
- AWS Glue Jobs:           ETL processing
- AWS Glue Crawler:        Schema discovery
- AWS Glue Data Catalog:	 Metadata repository
- Amazon Athena:	         SQL querying

Step 5: Create the employee-attendance-etl Job
1. Open AWS Glue Console.
2. Create a new Job.
3. Select the appropriate IAM Role.
4. Configure the script location: s3://lynne-data-engineering-labs/week7/project_employee_etl/scripts/employee_attendance_etl.py
5. Save the job.

The ETL script automatically:
- Reads employee details from the designated S3 location.
- Reads attendance data from the date-partitioned attendance folder.
- Performs data cleansing and transformations.
- Combines employee details and attendance records.
- Writes the processed output to the configured date-based partitioned folder.

# Execution Flow
1. Upload attendance data to the partitioned S3 folder.
2. Start the employee-etl-workflow.
3. The workflow runs:
  - fetch-employee-job
  - employee-attendance-etl
  - employee_attendance_crawler
4. Query the processed data using Amazon Athena.
